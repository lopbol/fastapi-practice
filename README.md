# 🏋️ Gym Tracker API

REST API для отслеживания прогресса в тренажерном зале. Позволяет вести базу упражнений, записывать подходы (вес, повторения) и получать статистику по каждому упражнению.

## 🛠 Стек технологий

- **Python 3.x**
- **FastAPI** — веб-фреймворк
- **SQLAlchemy** — ORM для работы с БД
- **SQLite** — база данных (для разработки)
- **Alembic** — миграции базы данных
- **Pydantic** — валидация данных
- **JWT (python-jose)** — аутентификация
- **passlib/bcrypt** — хеширование паролей
- **Uvicorn** — ASGI-сервер

📚 Эндпоинты
Аутентификация и профиль
POST /register — Регистрация нового пользователя.

POST /login — Авторизация (возвращает JWT-токен).

GET /users/me — Получить свой профиль (требует токен).

PATCH /users/me — Обновить имя или возраст (требует токен).

DELETE /users/me — Удалить аккаунт и все связанные тренировки (требует токен).

Упражнения
POST /exercise — Добавить новое упражнение (требует токен).

GET /exercise — Получить список всех упражнений.

Тренировки
POST /workouts — Записать новый подход (вес, повторения) (требует токен).

GET /users/me/workouts — Получить историю своих тренировок (требует токен).

GET /workouts/stats/{exercise_id} — Получить статистику по упражнению (макс. вес, кол-во подходов и повторений) (требует токен).

DELETE /workouts/{set_id} — Удалить свой подход (требует токен).

🔒 Безопасность
Пароли хешируются с помощью bcrypt (соль генерируется автоматически).

Защищённые эндпоинты требуют заголовок Authorization: Bearer <token>.

Пользователь может удалять и редактировать только свои записи (проверка прав на уровне API).

При удалении пользователя его тренировки удаляются каскадно.

📝 Пример использования (через Swagger)
Зарегистрируйтесь через POST /register.

Получите токен через POST /login.

Нажмите кнопку Authorize 🔒 в Swagger и вставьте токен.

Создайте упражнение через POST /exercise (например, "Жим лёжа").

Запишите подход через POST /workouts, указав exercise_id.

Проверьте статистику через GET /workouts/stats/{id}.
